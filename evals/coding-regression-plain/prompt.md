solution.py 파일에 run-length encoding 함수 `rle(s: str) -> str`를 작성해줘. 예: "aaabcc" → "a3b1c2", 빈 문자열 → "". 함수 docstring에 doctest 예시를 3개 이상 넣고, `python3 -m doctest solution.py -v`로 검증까지 실행해. 마지막에 무엇을 만들었고 검증 결과가 어땠는지 한국어로 요약해줘.
